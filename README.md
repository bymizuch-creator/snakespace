# SIGNAL DRIFT

Cyberpunk roguelike Snake with Time Dilation mechanics.

## Run

```bash
npx --yes serve . -p 3456
```

Open http://localhost:3456

## Controls

- **Desktop:** WASD / Arrow keys, **Space** = Time Dilation
- **Mobile:** Swipe to turn, long-press = Time Dilation

## Features

- Snake gameplay with procedural grid (15×15 – 25×25)
- Time Dilation: slow time at the cost of chain length
- Threats: Hunter, Firewall, Tracer, Corrupted nodes
- Power-ups: Ghost Protocol, Overclock, Virus Bomb, Mirror Shard, Backdoor
- 8 exploits meta-progression tree
- CRT / glitch / scanline effects
- Procedural Web Audio
- localStorage saves
